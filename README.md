# Portfolio Snapshot

拉取持仓信息、保存每日快照并生成单文件 HTML 投资组合报告。

## 生成报告

```powershell
python generate_report.py
```

运行后会生成：

- `report.html`：完整投资组合报告，内含重仓股持有时间线模块。
- `timeline.svg`：可单独使用的买入到清仓时间线。

## 页面显示

1. 页面最上方显示最近更新时间（北京时间），随页面自然滚动，不固定悬浮。
2. 默认报告区间为北京时间今年 `1/1` 至今天；页眉仅保留开始、结束日期选择，完成任一日期选择后立即刷新，无需点击按钮。
3. 区间切换更新快照走势图、期末持仓与统计；无快照或日期无效时提示原因并保留上次有效报告。
4. 持有时间线和历史年化收益保留完整记录，不受日期筛选影响；非饼图铺满内容区宽度，饼图保留原有布局。
5. 页面容器与卡片不显示装饰边框；表格恢复原有样式：浅灰外框、深色表头及合计横线、浅灰行分隔线，无单元格竖线；图表内部曲线、坐标轴和网格线保持不变。
6. 折线图（资产·收益·收益率/回撤/仓位率）使用 ECharts：十字光标吸附日期点，读数固定图表左上角、日期与数值同一行；折线标注最大值与最小值（带单位：金额用万、比率用 %，多线同屏时标签按车道纵向错开并带白底）；主图三条线为蓝/青/橙实线（资产/收益/收益率）；移动端图例移到图表下方、Y 轴刻度与标题全部隐藏、线宽更细、图表铺满屏幕全宽，拖动十字光标每切换日期点有触感反馈（Android 需 HTTPS，iOS 需 17.5+）；仓位率 Y 轴不设上限，超过 100% 正常显示。
7. 持仓收益排行使用 ECharts 横向条形：标的名称放在条形末端外侧（正收益在右、负收益在左），不占 Y 轴宽度；持仓明细表公司名称列在移动端横向滚动时吸附固定。

## 时间线配置

时间线的交易记录和显示设置统一维护在 `config.json` 的 `timeline` 节点：

- `trades`：标的名称、买入/清仓日期、本金、利润和年化收益率。
- `show_amount`：是否显示具体利润与仓位。
- `layout`：时间线尺寸。

页面模块可通过 `sections.timeline` 显示或隐藏。

只生成独立 SVG：

```powershell
python generate_timeline.py
```
